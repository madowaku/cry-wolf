# CRY WOLF! 絵本のひと夜 v0.3

`index.html` をブラウザで開いて遊べます。同じフォルダのCSSとassetsを一緒に置いてください。NIGHT 2だけの独立試作で、3夜版・7夜本編との接続はありません。

右上の音ボタンで音をONにします。初期状態はOFF。画面下部の「♫ 音量」でBGMと効果音を調整できます。BGMは繰り返し再生し、場面の変わり目で短くフェードします。

| 場面 | 曲 / 作者 | 公式ページ |
| --- | --- | --- |
| タイトル・夕方 | the fairy tale / のる | https://opentracks.com/bgm/detail/19133 |
| 夜・調査・報告 | Storyteller / のる | https://opentracks.com/bgm/detail/21959 |
| 結果・振り返り | 月夜 / チョコミント | https://opentracks.com/bgm/detail/6987 |

音楽提供: OpenTracks。[音源利用ライセンス](https://opentracks.com/help/articles/license/)・[利用規約](https://opentracks.com/help/articles/terms/)。音楽はゲーム内BGMとして使用します。音源の再配布・素材としての提供を目的としたパッケージではありません。

プレイヤーはベル。足跡・声・ランタンの合図から今夜の状況を判断します。調査か合図を一つ選ぶと1刻、2刻が終わったら鐘／異常なしを選びます。ヘルプ・メモ・音量設定・ページ送りでは刻が進みません。見張り道にオオカミが入ったときだけ警報が必要です。

操作: クリック／タップ、Tab／Enter、ページ送りはSpace、説明や設定を閉じるときはEscape。セーブはありません。
