# CRY WOLF! — 月あかりの約束 v0.9.1

`index.html` をブラウザで開いて遊びます。すべてのファイルと `assets/` の位置関係を保ってください。外部CDN・API・バックエンドは不要です。

- 第一夜〜第七夜、4種類の結末と各3ページのエピローグまで遊べる絵本ゲームです。
- タップ／クリック、TabとEnter／Spaceで選択。読む場面はEnterで次へ。
- 読む時間に制限はありません。刻は調査・合図の行動でだけ進みます。
- 「手帳」で手がかり、「？」でルール、「設定」でBGM・効果音の音量、動き、人物の絵を確認できます。
- ページと選択を同じブラウザに保存。「しおりから読む」で再開します。三夜版v0.8のしおりも、元を残したまま第四夜へ引き継げます。保存を拒否する環境では画面にその旨を表示し、そのまま遊べます。別のファイル位置／URL／ブラウザ間の保存移動はありません。
- 音は最初OFF。端末の動きを減らす設定にも対応しています。

第二夜は、遠吠えと足跡を一つずつ読みます。ランタンの図では、灯りの届く範囲と気配の距離を見比べられます。調査中のルナは見えません。報告では、見張り道へ入ったかどうかという事実を確認して選びます。

各夜の結果は、まず人物の反応、その後に理由と数値を読みます。この追加のページ送りでは刻や選択履歴を増やしません。理由を読んでいる途中や、二つ目の手がかりのページからも、しおりで再開できます。

音楽は、タイトル・序章「the fairy tale」、七夜のプレイ「Storyteller」、結末・後日談「月夜」。曲は繰り返し再生し、場面の変わり目では短くフェードします。同じ場面のページ送りでは再生位置を保ちます。再読み込み後の音は、操作してから始まります。音量と動きの設定は同じブラウザへ保存します。

第四夜は贈り物への返事。第五夜は夕方の本音と、夜の報告を別に選びます。第六夜は残り3刻で村・森・道筋を確かめ、最後は満月の下で自分の言葉を選びます。村と森の道の行方も、後日談へ反映されます。

最後まで読むと、結末の記録が残ります。「設定 → 読んだ結末」で確認でき、新しく読み始めても消えません。読み終えた画面の「後日談を、読み返す」で、そのプレイの3ページをもう一度読めます。

ベル12表情、ルナ16表情を場面に合わせて使います。「設定 → 登場人物と絵を見る」から追加の人物画をまとめて見られます。

画像の出典は `CREDITS.md`、処理物の情報とSHA-256は `asset-manifest.json`。元データは本プロジェクトの `assets/illustrations/moon/` にあります。
