# 美術と制作記録

ユーザー提供 CRY WOLF v0.7.1 の3夜ルール・物語を土台に、2026-10-12の依頼で制作した七夜とエピローグの絵本ゲームです。後半はv0.3の贈り物・本音・最終対話と4ENDの構成を、観察と合図で判断するこの版へ合わせて実装しました。

ベルとルナの既存デザイン・ユーザー提供のルナ表情シートを参照し、Codex built-in Imagegenで表情を追加。ピップ（子どものウサギ耳の郵便屋）と村長（ヒツジの耳・角を持つ年長者）、村・見張り台・森の泉、鐘・足跡・月もImagegenで生成しました。人物は人の顔・体を持つ擬人化表現です。

配布用の37点は元PNGからWebPに変換し、人物・小物の透過を保持。表情シートはセル単位に切り出しています。隣のポーズのはみ出しを表示しないよう、ベルの一部はCSSで左端4%、ルナの新規右列4表情は左端8%をマスク。画素原本は保持し、左右反転はしていません。

v0.9では、第四夜の月形チャームと後日談の朝の村をCodex built-in Imagegenで生成しました。朝の背景は既存の夜の村を参照編集し、同じ村と見張り台の配置を保持。原本は `moon-charm.png`、`environment-village-dawn.png`。生成プロンプトはプロジェクトの `docs/moon/charm-prompt-v0.9.json` と `dawn-prompt-v0.9.json`。

v0.8.1でルナに8表情を追加。誇り高い普段顔、からかい、いたずら笑い、怒り、真剣、悲しみ、寂しさ、素直になりかける顔です。2枚の生成原本は `luna-pride.png` と `luna-heart.png`、正確なプロンプトと参照画像はプロジェクトの `docs/moon/luna-expression-prompts-v0.8.1.json` に記録。

初回の動物顔のピップ・村長と青年寄りのピップは不採用。今回の配布には入っていません。

背景・人物・小物と、HTMLの文章・UIは別レイヤー。フォントは端末標準の明朝系／Georgiaとシステムフォント。効果音はWeb Audioの短い合成音、初期OFF。第三者音源、外部フォント、外部CDNは使用していません。

生成プロンプトと採用判断はプロジェクトの `docs/moon/generation-prompts.json` と `DIRECTION.md`、元画像と変換物のSHA-256は同梱 `asset-manifest.json` に記録。第三者の商用利用許諾を取得・認証したという意味ではありません。
