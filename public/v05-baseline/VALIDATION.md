## 対象

シングルファイル `index.html`。ブラウザ版 Night 2「来ないって言ったのに」。

## 自動ブラウザ操作テスト

Playwright Python + システムChromium (`/usr/bin/chromium`)、`page.set_content` による隔離DOMテスト。

- 390×844 / 360×800 / 720×1280：3画面サイズ
- 各6手順：計18走行
- ルート：足跡→合図→異常なし（best）
- 別解：聞く→合図→異常なし（best）
- 誤報：足跡→合図→鐘（false）
- 正しい報告：足跡→聞く→鐘（duty）
- 見逃し：早期合図→聞く→異常なし（secret）
- 合図失敗後の正しい警報：早期合図→足跡→鐘（duty）
- 全18走行で期待の ending が一致、`phase=result`
- 水平オーバーフローなし、ボタンの矩形は全て縦横30px超
- helpダイアログ開閉PASS
- uncaught JS `pageerror` なし
- 390×844 / 360×800 のスクリーンショット取得
