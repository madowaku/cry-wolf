# CRY WOLF! v0.5 — 「二人だけの遠吠え」1夜Playable Experiment

## 遊び方

`index.html` をスマホ/PCのブラウザで開くだけ。依存ライブラリ・インストール不要。オフライン可。

## 検証したい体験

「来ない」と言ったルナが本当は会いに来ていることを、足跡や音から察する。
時間を使って調べるだけでは見張り道に入ってしまう。ランタンで「森側で待って」と伝えれば、仕事を守りつつルナと会える。

- **2刻**のあいだに調査（足跡／耳を澄ます）または合図を行う。
- 初期位置は「遠くの森」、1刻後は「境界の木陰」、2刻後は「見張り道の中」。ただし2刻目に有効な灯りの合図を送るとルナは境界の外に留まる。
- 灯りは近くにしか届かず、最初の刻に送ると不発。
- 2刻後、**「オオカミだ！」か「異常なし」**を必ず選ぶ。
- true wolf / reported wolf → 正しい警報
- no wolf / reported wolf → 誤報
- true wolf / no wolf reported → 見逃し
- no wolf / no wolf reported → 成功

## 全4結果（決定的・乱数なし）

| 条件 | 結果 | 信用 | きずな |
|---|---|---:|---:|
| 調査→届く距離で合図→異常なし | ふたりだけの、正しい約束 | 0 | +1 |
| 調査→届く距離で合図→警報 | まちがえた警報 | -2 | 0 |
| 調査2回 / 遠い時点で合図など→警報 | 正しい鐘の音 | +1 | 0 |
| 調査2回 / 遠い時点で合図など→異常なし | 甘くて、苦い秘密 | -1 | +1 |

- 試作品の「成功」は誠実な仕事と恋愛の両立。TRUE ENDを意味しない。
- N2単体の試作であり、七夜のノベル本編、既存セーブ、既存ステータスとは接続していない。
- ルナは選択に反応する。行動自体は物語上決定的。毎回同じ条件なら同じ結果。
- 日本語のみ。効果音は操作時のみ鳴り、音声OFFボタンあり。

## 実装ノート

- HTML+CSS+Vanilla JavaScript 1ファイル。Reactへの移植時は phase/state/outcome を分離する。
- イラストはプログラム的なインラインSVG。画像にボタン文字を焼き付けず、文字と操作をHTMLでレンダリング。
- `window.CRYWOLF_TEST.get()` は検証用に現在状態を取得できる。
- 収益化・外部公開に先立ち、A401OP実機で360×800表示、フォント、タッチ、音声を確認する。
