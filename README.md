# CRY WOLF! Romantic Variant

村の夜番ベルと、誇り高く勝ち気なオオカミ娘ルナ。仕事と本音の間で揺れる、全年齢・非暴力の短編恋愛読み合いゲーム。

## 月あかりの約束 / v0.9.2 — 七夜とエピローグ

既存ホームを正式な表紙へ整え、起動時の短いローディングと読み込み失敗からの復帰を追加しました。表紙は半月、ベルとルナ、村と森の境界。しおりがあるときは再開が主ボタンになり、読み直しは確認を挟みます。序章ではベルの仕事と手紙の道を守りたい理由を伝え、結果では「村の信用・ルナとのきずな・合図の理解」の実際の前後値、増減と理由を個別に読みます。七夜・4END・道・保存・立ち絵・BGM3曲のルールと素材を維持しています。変更と実施検証、5場面の比較画像は [v0.9.2報告](docs/moon/FINISHING_v0.9.2.md)。

ユーザー提供v0.7.1の3夜版を土台にした新しい絵本版は **[http://127.0.0.1:5198/moon/index.html](http://127.0.0.1:5198/moon/index.html)**。`npm run dev -- --port 5198` で起動します。既存のトップ画面にも入口を追加しました。

指定コミット `510626d333e5a11fdc31f748a72d31b39bdb20f2` を土台に、ひと夜storybook版の演出と3曲のBGMを取り込みました。第二夜は遠吠え→足跡を別ページで提示し、調査は人物の姿を隠して距離とランタンを主役に、報告は大きな鐘を中心に描きます。各夜の結果は人物の反応→理由と数値の順に読みます。追加のページでは刻・ゲームの選択履歴は増えず、表示内のページ位置もしおりから復帰できます。BGMはタイトル・序章「the fairy tale」、七夜のプレイ「Storyteller」、結末・後日談「月夜」。設定で音をONにし、BGMと効果音を別々に調整できます。詳細は `docs/moon/IMPORT_STORYBOOK_v0.9.1.md`。

子どものウサギ郵便屋ピップとヒツジの村長を、ベル・ルナと同じ人の顔と体を持つ姿で追加。ベル12表情（困る・たじたじ・考え込む等）、ルナ16表情、村・見張り台・森の泉、鐘・足跡・月を組み込みました。ルナは誇り高い普段顔、からかい、いたずら笑い、怒り、真剣、悲しみ、寂しさ、素直になりかける顔を追加し、会話と結果に合わせて使います。設定から絵の一覧、効果音、動きのON/OFFを選べます。表情の更新記録は `docs/moon/LUNA_v0.8.1.md`。

## 絵本のひと夜 / Flat Pop v0.1

**NIGHT 2「来ないって言ったのに」を単独で遊べる絵本UI**を追加しました。3夜版のタイトルにある「絵本のひと夜を遊ぶ」、または開発サーバーの <http://127.0.0.1:5193/storybook/index.html> から開けます。

夕方の強がりとベルの反応 → 遠吠え → 足跡 → 1刻ずつの調査・合図 → 鐘／異常なし → 二人の反応 → 理由と数値、をページ送りで見せます。美術は大きな色面と月、簡素な衣装、顔・耳・尻尾を中心にしました。ルナは勝気な目線とからかいを普段の表情にし、待っていた結果で柔らかさを見せます。

ブラッシュアップ版の専用プレビューは <http://127.0.0.1:5197/storybook/index.html>。`npm run dev -- --port 5197` で起動します。同じポートで別の試作を使っている場合や、ブラウザに別ゲームが表示される場合に、この専用ポートを使ってください。更新した距離の図・報告の事実・結果の構図と検証は `docs/STORYBOOK_POLISH_v0.2.md` を参照。

ZIPで提供された**v0.5独立試作のルールを維持**しています。夜は2刻、行動は足跡／音／ランタン。1刻目の合図は届かず、2刻目は届きます。2刻終了後に必ず報告。`track→signal`、`listen→signal`、`signal→signal` のいずれも異常なしでBESTになります。

| 結果 | 村の信用 | 二人のきずな |
| --- | ---: | ---: |
| BEST / ふたりだけの、正しい約束 | 0 | +1 |
| FALSE / まちがえた警報 | −2 | 0 |
| DUTY / 正しい鐘の音 | +1 | 0 |
| SECRET / 甘くて、苦い秘密 | −1 | +1 |

これは3夜版の確率・ステータス・セーブとは別の比較実験です。7夜本編との接続はしていません。比較元は <http://127.0.0.1:5193/v05-baseline/index.html>。添付の元HTMLは変更していません。

寓話 → ベルの仕事 → ルナが落とした鐘を返す、の3画面で始まります。NIGHT 1はルナが見張り道にいると分かった上で、仕事の警報と「見逃して、少し話す」の間で選びます。翌朝の結果には足跡・報告と、村の信用／ルナとの仲が変わった理由を表示します。

NIGHT 2からは姿を隠し、夕方の予告と夜の兆候から推理します。確率、CRY/SILENTの数値処理、7夜のエンジンと4END条件はv0.3のままです。「？」でルールを確認でき、「物語とルールを見る」で進行を変えずに読み返せます。全文は即時表示。読了後はINTROをスキップできます。localStorageに記録するのはINTROの既読だけで、ゲームの保存とは別です。保存を使えない環境でもプレイできます。

ビルド結果は `dist/`。プレビューは <http://127.0.0.1:5195/>。Vite `base: './'`、API・外部フォント・CDN・バックエンドなし。ポートが使用中なら `npm run dev -- --port 5194` のように変更してください。

## 再現とデバッグ

- `/?seed=0`：同じseedと同じ選択で、同じ来訪・兆候・状態に到達します。
- 新しい通常プレイはブラウザの乱数からseedを作成します。ゲームの抽選はseedを明示的に受け取る純粋関数です。
- 開発サーバーのみ、例 `/?seed=0&visit2=0&sign2=TRACE&visit3=1&sign3=QUIET` でN2/N3の来訪と兆候を指定できます。`visitN=0/1`、`signN=QUIET/RUSTLE/TRACE`。N1/4/7の固定ルールは上書きできません。本番ビルドでは強制指定は無効です。
- UIは3夜に固定されています。7夜の再現手順は `docs/QA.md` と `docs/qa-routes.json` を参照してください。テスト用 `play()` は7夜のエンジンを実行します。
