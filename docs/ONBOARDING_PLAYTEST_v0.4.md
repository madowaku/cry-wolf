# CRY WOLF! — Onboarding Hotfix v0.4 実装・検証記録

2026-10-11 JST。ユーザー依頼に基づき、添付v0.4を差分仕様として適用。基本ルールはv0.3を維持した。

## 実装範囲と前提

調査時の実装はT001〜T003、NIGHT 1〜3のUIと仮リザルト。NIGHT 4〜7・4ENDは純粋エンジンに実装されているが、専用画面とゲーム保存／つづきからは未実装だった。このHotfixで全7夜UIや保存を新設していない。

`src/core/config.ts`、`rules.ts`、`engine.ts`、`rng.ts`は改修前後のSHA256が一致。来訪／兆候確率、数値変動、END条件、抽選タイミングを維持。`types.ts`は会話の話者「村長」「ナレーション」を追加しただけで、GameStateの保存対象構造は変更していない。

## 冒頭フローの変更

| 改修前 | 改修後 |
| --- | --- |
| 見張り道・兆候・足跡の説明から開始 | INTRO 3画面：寓話 → 村長からベルへの仕事紹介 → ルナが鐘を拾って返す |
| 初夜にも「今日はもう来ない」の予告と、姿のない推理 | 初夜はルナが見張り道にいると公開。仕事と、もう少し話したい気持ちで選ぶ |
| 初夜に「何もいない」 | 「見逃して、少し話す」。補足に報告を「異常なし」にすることを明記 |
| N2/3の兆候だけを選択画面に残す | 夕方の予告と兆候の説明を両方残す。N2の夜に初めて推理のヒント |
| 数値の増減と足跡報告 | 来訪の真偽 → 会話 → 翌朝の足跡と報告 → 実際の増減と理由 |
| メニュー内の短い説明 | 常設「？」と「物語とルールを見る」。読み直しても進行・乱数・数値は変わらない |

全文は即時表示で文字送りアニメなし。INTROはタップ／クリック／Enterで進む。読了後の既読スキップを用意し、`はじめから`では毎回INTROを開く。初回のN1だけ説明カードを出し、再プレイでもルナの場所と翌朝の足跡確認は残す。既読は独立したlocalStorageキーに記録し、ゲームのセーブとは区別する。ストレージを拒否された場合も新規プレイ可能。

N2不在＋CRYの条件付き好感度は維持。「後日ルナが警報の噂を聞いた」と説明し、不在の夜にルナが直接話したようには表示しない。翌朝の画面ではルナの立ち絵を隠す。下限／上限で増減が止まった場合は、実際の差分0と限界を表示する。

## 修正した不具合

- N1の新しい話者「村長」を既存会話テストの合法話者に追加。
- 仮リザルトに各夜の理由を重複表示すると360×800でボタンが見切れた。各夜の結果に理由を保持し、仮リザルトは選択・来訪・増減に整理。
- 既読スキップのダブルクリックが、位置の重なった次の画面のボタンを押した。会話・INTROの進行操作で同一ジェスチャーの2回目を無視するよう修正。
- INTROの章と立ち絵の更新が別タイミングになった。同じクリック処理で両方を更新するよう修正。

すべて修正後に関連検証を再実行。実施範囲に未解決のBLOCKER/HIGHは検出していない。本番プレビューの5195ポートはこの環境で応答しなかったため、5196で実際に確認した。
