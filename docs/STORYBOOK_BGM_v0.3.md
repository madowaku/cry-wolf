# 絵本UI BGM v0.3 — 2026-10-12

対象は独立NIGHT 2の `public/storybook/index.html`。v0.5の18経路、2刻、判定と結果の数値を維持する。3夜版の音楽やルールを変更していない。

## 選曲と再生

| 場面 | 曲 / 作者 | 原音の長さ | 公式ページ |
| --- | --- | ---: | --- |
| タイトル・夕方 | the fairy tale / のる | 79.60秒 | https://opentracks.com/bgm/detail/19133 |
| 夜・調査・報告 | Storyteller / のる | 161.13秒 | https://opentracks.com/bgm/detail/21959 |
| 結果・振り返り | 月夜 / チョコミント | 31.32秒 | https://opentracks.com/bgm/detail/6987 |

ユーザーが手動で入手し `BGM` に置いた原音3曲を採用。再取得はしていない。原音を保持し、FFmpegでAAC 128kbps / 44.1kHz / stereoへ変換する。変換物をゲーム専用JSコンテナへ格納し、通常のMP3／M4Aファイルとして配布ZIPへ含めない。`npm run music:pack` で再取り込み可能。ソースおよび変換物のSHA-256は `storybook-music-receipt.json`、配布コンテナの記録は `public/storybook/music-manifest.json`。コンテナは単純な難読化で、DRMではない。

音は初期OFF。右上の音ボタンを押した後に再生する。BGMの初期音量は22%、合成SEは70%。下部の「♫ 音量」からそれぞれ調整できる。設定を閉じても選んだ音量を保持するが、ページを再読み込みすると初期値へ戻る。

同じ曲を使うページは再生位置を継続。曲が変わる場面では450msのクロスフェード、再挑戦はオープニングへ戻る。各曲をループする。表示中の曲名・作者・公式ページリンクを設定内へ載せた。音量設定ではゲームの刻が進まず、背後の入力を遮断し、Tabをダイアログ内に留め、Escapeで元のボタンへフォーカスを戻す。

ミュートはBGMとSEを即時に止める。タブが隠れたときは一時停止する設計。未入手・破損・自動再生拒否の場合もゲームを停止せず、設定に再生状況を示す。Blob URLを用い、音源サイトへの直リンク再生や実行時ネットワーク取得は行わない。詳細な出典と公式条件は `ASSET_PROVENANCE.md`。
