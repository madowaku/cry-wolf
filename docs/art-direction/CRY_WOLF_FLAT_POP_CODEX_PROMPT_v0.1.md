# Codex開始指示 — CRY WOLF! Flat Pop Art Direction v0.1

既存の『CRY WOLF! Romantic Variant』の **Storybook Slide UI v0.1** に、添付の `CRY_WOLF_FLAT_POP_ART_DIRECTION_v0.1.md` をビジュアル正本として適用してください。 `cry-wolf-tokens.css` を使い、タイトル・会話・調査・報告・結果に共通するデザインを段階的に制作してください。

## 最優先

1. 既存アプリが**単一HTML＋CSS＋Vanilla JS**であれば、移植せず差分適用。Reactへ勝手に移植しない。作業前に実際のコードとロジック／UI分離状況を確認。
2. 現在の v0.5 **2刻／track・listen・signal／4結果と数値変動を絶対に変更しない**。ゲーム性改修は別のタスク。
3. まず**CSSデザイントークン**とレイヤー構造を整理し、**タイトル→夕方→調査→報告→BEST結果**の5画面を同じ作品に見えるように統一。カード・選択ボタン・字幕はHTML/SVGで描き、背景に文字を焼き込まない。
4. ベル（ボーダーコリー少年：片折れ耳、白い顔筋、ランタン／鐘）とルナ（灰銀オオカミ少女：尖った耳、大きな尾、小さな赤リボン）の**シルエットと表情**を主役にする。既存生成イラストの細密な服、髪、花、金装飾を引き継がない。
5. NIGHT 2調査・報告では**ルナの姿を出さない**。夕方と結果では表示してよい。足跡・境界・合図の届く距離は解法に必要な視覚情報として明確にする。
6. スマホ360×800／720×1280、PC、ミュート、reduced motion、Enter／タップ、説明とメモの再確認を点検。タイトルの『つづきから』は存在しないセーブのとき有効にしない。

## 素材の作り方

- まず `STYLE_PREVIEW.html` の絵本UIモックとトークンを参照して画面を統一する。**モック内のシルエットは仮の図形であり、正式立ち絵ではない**。
- アセットが必要なら**マスター立ち絵2点**（ベル、ルナ）を先に固定し、表情差分を派生制作。既存の生成画像は見た目の方向の参照としてのみ使う。
- 背景3枚（月夜、夕方、境界）＋人物2体＋アイコン3点をP0。リッチアニメや追加ステージは後回し。
- 画像生成ツールにアクセスできない場合も、既存SVG・CSSを整えて「何が不足しているか」を報告し、**無関係な画像を勝手に差し込まない**。

## 完了報告

変更ファイル一覧、画面スクリーンショット（360×800：title/evening/clue/report/best）、4結果の回帰検証、実機／人間テストの実施状況、残アセットの一覧を報告。ゲーム性が面白くなったかは**未試遊なら未検証**と明記。
