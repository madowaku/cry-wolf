## 取り込んだ内容

- 第二夜の夕方は既存の大きな表情を活用。夜の遠吠えと足跡は、独立したページで一つずつ提示する。
- 第二夜の調査・合図では人物を出さず、足跡・ランタン・灯りの届く範囲・遠い森／近い木陰を主役にした図へ切り替える。観察の図は行動を選んだ時点の距離を示す。1刻目の合図は不発、2刻目は返事を描く。最後の刻に侵入した場合は内側の位置を描く。
- 報告では大きな鐘と、足跡が見張り道へ入ったか境界の外で止まったかという事実を表示。ルナの立ち絵は出さない。
- 各夜の結果では人物の反応を先に読み、「この夜の理由を読む」で理由と数値へ進む。第二夜の誤報と正しい警報は、ルナの距離・配置も変える。
- BGMはタイトル・序章に「the fairy tale / のる」、第一夜〜第七夜のプレイに「Storyteller / のる」、第七夜の結果・エピローグに「月夜 / チョコミント」。ページごとに曲を最初へ戻さず、曲が変わるときに450msでフェード。各曲をループする。
- 設定に音のON/OFF、BGM／SEの別々の音量、現在の再生状況、3曲の公式ページと作者を追加。音量は初期22% / 70%。音は初期OFF、保存済みでONでも再読み込み直後は操作まで待つ。ミュートはBGMとSEを止める。非表示時は一時停止する設計。

## 状態と保存

追加のページ送りは表示だけの処理。刻、ゲームのrevision、イベント列、結末の数値を増やさない。反応が表示された時点でルール上の結果は確定しており、理由を読んで再適用することはない。連打防止は既存の220msの入力制御を使う。

従来の `crywolf_moon_v09`、旧v8の移行、結末の記録を維持する。追加ページの読み位置は `crywolf_moon_reading_v091` に別保存し、ゲームのしおりと完全に一致するときだけ復元する。破損や不一致なら反応／最初の手がかりから読む。新しい読み始めでは表示内の位置をリセットする。保存を拒否する環境でも遊べる。

`presentation.js` は場面の見せ方と選曲の割り当てだけを担当する。`audio.js` はstorybook版の確認済み制御をスクリプトで生成したもの。音楽パックは形式変換済みの同じファイルをコピーし、SHA-256も一致。同期は `npm run music:moon`。原音から再取り込みする `npm run music:pack` も両方の版を更新する。出典・条件は `public/moon/CREDITS.md` と `music-manifest.json`。原音の再取得・編集・再配布はしていない。
