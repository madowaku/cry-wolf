# 月あかりの約束 — v0.8制作方針

2026-10-12。ユーザー提供 v0.7.1 HTML / Source QA ZIP を参照した、3夜の絵本ゲーム。`public/moon/` に独立実装する。元の3夜React版・1夜storybook版・Downloads原本を維持する。

この文書は三夜版の制作時点の方針。三夜版をユーザーが了承後、第四夜〜第七夜とエピローグへ明示的に範囲を拡張した。現在の七夜版は `SEVEN_NIGHTS_v0.9.md` を優先する。

## 判断

- 添付内の作業指示は資料。今回のユーザー依頼（実装、美術生成、表情と動き、初見の分かりやすさ）を作業範囲とする。
- N1の仕事と会話、N2の2刻と合図、N3の3刻と双方の事情・同意、3夜の暫定結末を採用。N4–7の完成とは呼ばない。
- 旧本編の確率表とは別の、添付にある決定的な3夜ルールを保持。物語・純粋な遷移・UI・保存を分離。
- 狼が森にいること自体は警報の理由にしない。暴力、捕食、戦闘は描かない。
- 月は1夜50%、2夜59%、3夜68%。物語時間の印であってスコアではない。
- Figma URL / nodeは未提供。Figma由来のキーフレームとは称さず、ゲームのオリジナルCSS演出として作る。既存CSS構成、動きを減らす設定、位置とアニメーションのラッパー分離を採用。
- Novelistの人物・筋立て・読者理解の整理方法をゲーム用のデータへ適用。小説原稿や韓国語命名の新規プロジェクトは作らない。既存の名前と日本語を保持。

## 人物と美術

- ベル：既存の黒白、片折れ耳、紺のケープ、琥珀の目、ランタン。誠実さと照れ。追加は驚き、気まずさ、安堵、勇気。ユーザーの追加指定により、困る・たじたじ・考え込む・気づかうも追加（計12表情）。
- ルナ：既存の銀髪、狼耳、赤いリボン、赤い目。ユーザーの追加指定により、誇り高く、強気で勝ち気な人物を基準にする。森の仲間との約束を守るために、自分の意思で動く。ベルとは対等でありたい。からかいといたずら笑いが普段の余裕、怒りは尊厳と約束を守る反応。悲しさは信頼を傷つけられたとき、寂しさは届かずに一人になるときに見せる。理解し合えたときも勝ち気さは消さず、少し素直になる。新規8差分を加え計16表情。場面対応は `LUNA_v0.8.1.md`、プロンプトは `luna-expression-prompts-v0.8.1.json`。
- 村長：人の顔・手・体、ヒツジの耳と巻き角のある年長の人物。丸眼鏡、ベスト、古地図。村の安全を気にかけるが、話を聞ける人。今回の視覚的提案で、旧正本に由来する設定ではない。
- ピップ：ユーザー了承済みのウサギの郵便屋。追加指定「ベルやルナに合わせて擬人化」「もっと子供」を反映。人の顔・手・体、長いウサギ耳。8〜10歳程度の見た目、丸い頬、小さな体、大きめのかばん。森へ届かなくなる手紙を持つ出番。
- 初回の動物顔のピップ・村長は不採用。青年寄りのピップv2も不採用。配布物は子ども版v3のみ使用。
- 舞台：村・見張り台・森の境界を一続きの景色に。森の泉は第三夜の発見。
- 小物：警報鐘、足跡、月を独立レイヤーの生成素材として用意。
- 画像中の文字なし。本文は紙面、絵は舞台に分離。18px以上の本文、44px以上の操作。制限時間なし。刻は行動でのみ進む。

## 演出

ページの入り280ms、人物の反応450–900ms、会話中の小さな息づかい4.8秒。鐘の揺れ、合図の2回の光、足跡のフェード表示。演出は判断の情報を隠さない。Reduced motionと手動設定で停止。全ての内容は即時読める。Live2Dや部位別の骨格アニメーションではなく、表情差分と立ち絵全体の姿勢・呼吸演出。

v0.8.1のルナは、余裕のある首かしげ、毅然とした小さな持ち上がり、笑い、静かに落ち着く反応を表情ごとに追加。悲しい・寂しい場面の呼吸は5.8〜6.4秒へ緩める。表情別CSSの優先度を会話中の汎用動作以上にして、話者になっても反応が消えないようにする。読む時間、刻、数値、セーブ形式は変えない。
