# Codex用開始プロンプト：CRY WOLF! Storybook Slide UI v0.1

『CRY WOLF! v0.5 二人だけの遠吠え』の独立Playable Experimentを、添付した `CRY_WOLF_STORYBOOK_SLIDE_UI_IMPLEMENTATION_TASK_v0.1.md` に従って **絵本風立ち絵のスライドUI**へ改修してください。

まず `cry-wolf-v05-prototype/index.html`（または同等のv0.5ゲーム実装）と `README.md`、`VALIDATION.md` を読んで既存仕様を確認してください。

**重要な目的:** 1画面に情報を詰め込んだUIを、「夕方の予告→夜の異変→調査→合図→報告→結果」というページめくり体験に変え、ベルとルナの表情を大きく見せること。**ゲームの判定やステータスを変更しない**こと。

**必ず守ること:**
- 現行v0.5は HTML+CSS+Vanilla JavaScriptの単一ファイルです。**React移植や新規依存追加はしない**でください。
- 夜は2刻、行動は `track/listen/signal`。最初の刻の合図は届かず、2刻目の合図は届く。2刻終了で必ず報告です。
- BESTは `track→signal` と `listen→signal` の両方で成立します。`signal→signal` でも2刻目に合図が成功します。
- 4結果・信用/きずなの変化値は添付仕様書の表を正本としてください。
- 夜の調査と報告中はルナの姿を表示しない。夕方・結果では立ち絵と表情を主役にする。
- スライド送り・ヘルプ・メモ参照で刻を消費しない。選択の適用は一度だけです。
- 360×800の縦画面でテキスト・ボタンを読みやすくする。アート内へテキストやボタンを焼き込まない。
- 新規素材が足りなければ現行SVGを簡略化・拡張して使い、先にプレイ可能版を完成させてください。

**作業手順:** ベースライン確認→ページ/立ち絵基盤→2刻の調査分岐→報告と4結果→フラットポップ表現→自動QA→スクリーンショット→READMEと検証記録。

**完了報告:** 起動方法、新旧画面の違い、変更ファイル、全18行動経路の回帰テスト、360×800等の画面検査、撮影したスクリーンショット、未検証事項をまとめてください。人間プレイテストをしていない場合は、面白さは未検証と明記してください。

**今回はNIGHT 2だけで止めてください。** 7夜本編やエンディングの移植、ゲームルールの変更は別タスクとします。
