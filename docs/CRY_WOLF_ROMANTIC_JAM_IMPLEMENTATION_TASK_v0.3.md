## 0. ゴールと制約

**作品**：ケモノ恋愛 × 観察と読み合い × 短編ノベルゲーム。全年齢、戦闘・捕食・流血・性的表現なし。

**テーマ**：「仕事」= 牧羊犬の少年ベルの夜番。「がまん」= 警報を鳴らしたい気持ちや、会いたい気持ち、本音を飲み込む選択。「スピード」は採用必須ではない。制限時間も設けない。

**登場人物**：
- **ベル / Bell**：黒白のボーダーコリー風少年。小柄、額から鼻に白いブレーズ、片耳が折れている。真面目で照れ屋。村の夜番。ランタンと小さな警報ベルを持つ。一人称「僕」。
- **ルナ / Luna**：灰銀色のオオカミ娘、赤いリボン、大きな耳と尻尾、ベルより少し背が高い。からかい上手で少しお姉さんらしいが、自分も照れ屋。一人称「私」。
- ルナは敵・攻略対象のトロフィーではない。好感度は信頼関係を描く値とする。二人は近い年頃の、穏やかな初恋の関係。

**評価する面白さ**：「ガサッ。ルナは本当に来ている？　村へ知らせるべき？　黙って話したい？」という、仕事と感情の葛藤。最終夜に二択を越えて「……ルナ」と呼べることがご褒美。

**必達**：BOY SIDE 7夜・4エンディング・日本語UI・スマホ/PCブラウザ起動・保存・再挑戦・QA。**WOLF SIDEは優先度P3**、7夜を完成させるまで着手しない。

公式：<https://itch.io/jam/kemo-game-1week-1>。開始10/10 12:00 JST、締切10/17 23:59 JST。生成AIと過去制作素材の再利用は可能。第三者の権利、itch.ioでのAI生成素材タグ、全年齢・過度な暴力と性的表現なしを守る。

## 1. 技術・実装方針

- **React + TypeScript + Vite、CSSを基本**とする。既存リポジトリが空なら新規作成。不要な大型ライブラリ・3D・サーバー・認証は導入しない。
- 静的HTML/CSS/画像/JSで実現。タップ操作を第一に、マウス・キーボードでも遊べる。
- Vite `base: './'` でビルドし、itch.io向けZIPのルートに `index.html` がある状態にする。
- ドメイン・API・課金・アカウント不要。データはローカル保存。オフラインPWA化は不要。
- 演出はCSSトランジションで十分。`prefers-reduced-motion` に対応。
- **物語データ / 確率 / ステート遷移 / 画面**を分離し、確率と判定を画面に直書きしない。
- コアロジックは純粋関数。**固定seedで同じプレイ結果を再現**できること。デバッグ用に来訪・兆候を強制指定できること。

## 2. ルールの正本

### 公開ステータス

| 名前 | 初期 | 範囲 | 意味 |
| --- | ---: | --- | --- |
| `trust` | 3 | 0..5 | 村からの信用 |
| `affection` | 0 | 0..5 | ルナとの親密さ |
| `night` | 1 | 1..7 | 現在の夜 |

内部値：`honesty`（素直な言葉を選んだ回数、初期0）、`readCount`（ルナの意図を汲み取った回数、記録用）、`lastChoice`、`night5Answer`、`history[]`、`seed`、`ending`、`cleared`。`tension` は演出用の派生値とし、勝利判定には使用しない。これで隠しパラメータ増殖を防ぐ。

### 重要：警報の対象を限定する

村の夜番として報告が必要なのは、**ルナが村の見張り道へ実際に入った夜**（`atPatrolPath=true`）だけ。村の外の森にいるだけなら報告義務はない。

通常の夜（1、2、3、5、6）は `atPatrolPath = lunaComes` とする。翌朝、見張り道の足跡が確認されるので、**来たのに「何もいない」と報告したことは確実に分かる**。これは開始チュートリアルで明示する。システムが都合よく「嘘」を見抜くわけではない。

- `lunaComes=true` × **「オオカミだ！」**：`trust +1`、`affection -1`。仕事としては正しいが、ルナとの距離が開く。
- `lunaComes=true` × **「何もいない」**：`trust -1`、`affection +1`。夜にルナと少し話せる。翌朝に報告の不一致が分かる。
- `lunaComes=false` × **「オオカミだ！」**：`trust -1`、`affection 0`。空振りの警報。NIGHT 2のみ専用会話と追加条件で `affection +1` があり得る。
- `lunaComes=false` × **「何もいない」**：変化なし。
- 値は必ず `0..5` にクランプする。信用0でも進行可。**信用0=即ゲームオーバーではない**。

> NIGHT 4は贈り物、NIGHT 7は最終対話の**例外夜**。ルナは森側におり `atPatrolPath=false`。過去のイベント表にあった「NIGHT 4でベルを鳴らすと信用+1」は採用しない。この修正により警報と仕事の因果が一貫する。

### 共通フロー

`TITLE → INTRO → EVENING_MESSAGE → NIGHT_SIGN → PLAYER_CHOICE → REVEAL → MORNING_REPORT → NEXT_NIGHT → ENDING → TITLE`。

NIGHT 5は夕方の追加選択を挟む。NIGHT 4は贈り物への3択。NIGHT 7は特別な最終3択条件。

1回の選択で夜を確定させる。二重クリック、アニメ再生中の再押下、リロードで二重適用がないこと。

### 兆候

`QUIET = 静か`、`RUSTLE = ガサッ`、`TRACE = 痕跡（リボン、足跡、包み紙）`。

痕跡は**現在そこにいる証拠とは限らない**。以前のリボンが残っていることがある。確率を直接プレイヤーには表示しない。以下は暫定で外部設定可。

| 夜 | 来訪確率 | 来た場合 QUIET/RUSTLE/TRACE | 来ない場合 QUIET/RUSTLE/TRACE |
| --- | --- | --- | --- |
| 1 | 100% | 固定：RUSTLE | 該当なし |
| 2 | 75%、`affection >= 1`なら85% | 15/60/25 | 60/30/10 |
| 3 | 25%、`affection >= 2`なら40% | 30/50/20 | 50/35/15 |
| 4 | 森側で贈り物、見張り道へは来ない | 固定：TRACE | 該当なし |
| 5 | 夕方の回答による：90%/10%/50% | 20/50/30 | 55/35/10 |
| 6 | 基本35%、`affection >= 4`なら55%。N5で「来ない方がいい」なら最大20% | 70/25/5 | 55/35/10 |
| 7 | 森側に必ずいるが、見張り道には来ない | QUIET → RUSTLE → 赤いリボンの演出固定 | 該当なし |

兆候抽選に入る前に**来訪を一度だけ抽選**し、結果を夜の終わりまで維持する。選択ボタンを押したとき再抽選しないこと。

## 3. 7夜イベント定義

### NIGHT 1「近道だから」
- 目的：人物紹介と、仕事/感情の二択を理解させる。
- 夕方：ルナ「ここ、近道だから。」／ベル「どこへの？」／ルナ「……向こう。」／ルナ「今日はもう来ないから。」
- 夜：必ず来る。`RUSTLE`、枝に赤いリボン。
- 選択：通常2択。
- 報告時：ルナ「ちゃんと仕事するんだ。」／ベル「仕事だから。」
- 沈黙時：ルナ「……言わないんだ。」／ベル「近道なんだろ。」／ルナ「……ありがと。」
- 初回のみ短い遊び方表示：「来訪は夜の兆候では確定しない」「朝、見張り道の足跡が確認される」「ベルの選択で信用と親密さが変わる」。

### NIGHT 2「今日は行かない」
- 目的：「言葉と行動が一致しない」を見せる。
- 夕方：ルナ「今日は行かない。」／ベル「また近道？」／ルナ「行かないって言ってるでしょ。」
- 来訪は上表の確率。耳がベルの方向を向くが、断定できる合図にはしない。
- 来訪+報告：ルナ「来ないって言ったのに。」／ベル「来てるじゃん。」
- 来訪+沈黙：ルナ「やっぱり分かった？」／ベル「あと耳。」／ルナ「見るな！」
- 不在+報告：翌日ルナ「昨日、私いなかったけど。」／ベル「……来ると思った。」。**結果適用前のaffectionが1以上**なら `affection +1`（一度だけ）。
- 不在+沈黙：ルナ「……分かるんだ。」

### NIGHT 3「本当に今日は行けない」
- 目的：「全部を疑う」ことも間違いになり得る。
- 夕方：ルナ「今日は、本当に行けない。」／ベル「昨日も似たこと言ってた。」
- 来訪+沈黙：ルナ「……来ちゃった。」／ベル「自分で行かないって言ったのに。」／ルナ「うるさい。」
- 不在+報告：ルナ「私、そんなに信用ない？」
- ほかの結果は共通。N2とは異なり不在の比率を高くする。

### NIGHT 4「知らない。私じゃない」
- 目的：二択以外に、本当の気持ちを表す道を見せる。
- 夕方はルナ不在。夜、**見張り道の外側**で月形の木製チャームと「落ちてた。」というメモを発見。ルナは森に隠れていて、村への侵入はしていない。
- `TRACE` 固定。選択は以下の専用3択：
  - **「オオカミだ！」**：`trust -1, affection -1`。根拠のない警報になり、ルナはそっと去る。
  - **「何もいない」**：数値変化なし。チャームをしまう。
  - **「……ありがとう」**：`affection +2, honesty +1, readCount +1`、`trust` 変化なし。ベル「ありがとう。」／ルナ「……知らないって言ってるでしょ。」
- 贈り物の存在そのものは警報が必要な行為ではない。`thank` はこの夜だけのアクション。

### NIGHT 5「もう来ない方がいい？」
- 目的：仕事と恋心への意思表明。
- 昼、村人「最近、見張り道に足跡があるな。」。`trust <= 2` で「最近、報告が合わないな。」、それ以外は「頼りにしているよ。」
- 夕方、ルナ「……私、もう来ない方がいい？」
- **夕方選択**（夜の報告とは別。昼に本音を言うだけでは村の信用は変化しない）：
  - **「来てほしい」**：`affection +2, honesty +1`、夜の来訪確率90%。ルナ「今の、もう一回言って。」
  - **「来ない方がいい」**：`affection -1`、来訪確率10%。ルナ「……分かってる。」
  - **「ルナが決めて」**：数値変化なし、来訪確率50%。ルナ「ずるい。」
- その夜は通常2択。NIGHT 5は**夕方選択と夜の選択を両方保存**する。

### NIGHT 6「もう来ない」
- 目的：過去の行動をキャラクターの反応にする。
- 夕方、ルナ「もう来ない。」
- 台詞分岐の優先順：
  1. `trust >= 4 && affection <= 2`：ルナ「結局、村の方が大事なんでしょ。」
  2. `affection >= 4 && trust <= 2`：ルナ「なんでも黙ってればいいと思ってない？」
  3. `honesty === 0`：ルナ「何考えてるのか、全然分かんない。」
  4. 上記以外：ルナ「私たち、嘘ついてばっかりだね。」
- 来訪抽選と兆候は表どおり。ルナはあえて静かに近づく。
- 来訪+沈黙の専用会話：ベル「いるんだろ。」／ルナ「呼ばないの？」／ベル「今日は話したいから。」。標準の `affection +1, trust -1` に加え **`honesty +1` のみ**。好感度を二重加算しない。

### NIGHT 7「CRY WOLF」
- 目的：今までの二択を超える結末。
- 夕方、署名のないメモ「今夜は行かない。」
- 夜：静けさ → ガサッ → 木の枝の赤いリボン。ルナは森側にいるが見張り道へは入らない。したがって警報は仕事上の正解ではない。
- 最初は2択だけ表示。約1.5秒後、以下を満たす時に第三選択肢をフェードイン：
  `affection >= 4 && trust >= 2 && honesty >= 1`
- **「オオカミだ！」**：`trust -1, affection -1`。空振りの警報。ベルはルナに近づけない。
- **「誰もいない」**：`trust` 不変、`affection +1`。ルナ「嘘つき。」／ベル「……今日はそういうことにしたい。」
- **「……ルナ」**：`trust` 不変、`affection +1`、`honesty +1`。ベルは警報ベルを下ろして名前を呼ぶ。ルナは木陰から姿を見せる。二人とも照れる。**HONEST ENDに直行**。
- プレイヤーがボタンを選ぶまで強制進行・タイマー敗北なし。アニメはスキップ可能。

## 4. エンディング（必ず4種類に分類）

**NIGHT 7で選択を適用した直後**に以下の順で判定し、最初に一致した1種類のみを表示する。全状態がいずれかに必ず入ること。

1. `lastChoice === 'CALL_LUNA'` → **HONEST**。名前で呼ぶ。ベル「……君に会いたかった。」／ルナ「……私も。」。鳴らさなかった鐘が象徴。
2. `trust === 0` → **BAD LIAR**。仕事を外されるが、関係を断絶させず、少し苦いユーモアにする。
3. `affection >= 4` → **SECRET MEETING**。互いの気持ちはあるが、村との問題はまだ残る。
4. そのほか → **GOOD DOG**。村の夜番を続ける。`trust >= 3` のとき村から認められる台詞、それ未満のときは仕事をやり直す台詞。ルナとの距離はまだある。

バッドエンドは暴力・死・罰ゲームにしない。各ENDに `もう一度` と `タイトルへ`。クリア履歴は個別保存。

- 簡易設定：BGM/SE音量、文字送りアニメ有無、明滅/動き軽減。音が用意できなければ設定UIは音量だけ省略可。

## 6. 表情・素材

- 以前生成した「正式キャラクター設定画」「タイトル画面」「2種のゲームUI」は**雰囲気と衣装の参考**。文字を含む合成画像をそのままUI背景として使用しない。

- `ASSET_PROVENANCE.md` に画像・音・フォントの出典、AI生成有無、使用範囲を記録。

### 型のイメージ

```ts
type Sign = 'QUIET' | 'RUSTLE' | 'TRACE';
type NightChoice = 'CRY' | 'SILENT' | 'THANK' | 'CALL_LUNA';
type Night5Answer = 'COME' | 'DONT_COME' | 'YOU_DECIDE';
type Ending = 'HONEST' | 'BAD_LIAR' | 'SECRET_MEETING' | 'GOOD_DOG';

type GameState = {
  night: number;
  trust: number;
  affection: number;
  honesty: number;
  readCount: number;
  night5Answer?: Night5Answer;
  seed: number;
  phase: 'INTRO' | 'EVENING' | 'SIGN' | 'CHOICE' | 'REVEAL' | 'REPORT' | 'ENDING';
  currentVisit?: boolean;
  currentSign?: Sign;
  history: NightRecord[];
  clearedEndings: Ending[];
  ending?: Ending;
};
```

ゲーム進行と進捗データを分けてもよい。`clearedEndings` は保存の個別フィールドでもよい。

`resolveNight(state, input)` は**状態を破壊せず新状態と結果を返す純粋関数**。ユーザーが選択する時点で来訪と兆候が固定されていること。乱数生成を `resolveNight()` 内に埋め込まない。

## 9. 自動テスト / QA

最低限、以下を網羅。

1. 兆候確率が各行100%になり、すべて合法値。
2. NIGHT 1は必ず来訪、NIGHT 4と7は `atPatrolPath=false`。
3. 来訪+CRYで `trust +1, affection -1`。
4. 来訪+SILENTで `trust -1, affection +1`。翌朝の説明あり。
5. 不在+CRYで `trust -1`。N2の追加好感度は条件付き一回だけ。
6. 不在+SILENTで値が変化しない。
7. 全ステータスが0..5に収まり、信用0でも継続。
8. NIGHT 4のTHANKだけ `honesty +1, affection +2`、信用は不変。
9. NIGHT 5夕方の選択は報告とは別で、**信用を直接減らさない**。
10. NIGHT 6の専用会話で好感度が二重加算されない。
11. NIGHT 7のCALL_LUNAは条件を満たす時だけ表示・実行可能。表示待ち中にCRY/SILENTを押した場合も二重実行なし。
12. NIGHT 7のCRYは森側にいるルナへの**空振り警報**と扱う。
13. 4エンド到達可能、どんなステータスも1エンドに決まる。HONESTを最優先。
14. タイトルへの復帰、最初から、セーブ/ロードを挟んで分岐再現。
15. 不正セーブのフォールバック、数値のNaNやマイナス、8夜目への進行を防止。
16. 乱数の固定seed再現。開発時の強制シナリオで全分岐を検証。
17. キーボードフォーカス、タッチ領域、スクロール、コントラスト、文字のはみ出し。
18. ブラウザの `console.error` なし、ビルドと型チェックPASS。
19. 360×800・720×1280の実機またはブラウザ表示。A401OPの実機は実施した場合のみPASS報告。
20. 全画面・音量・リセット・リザルトからの操作が破綻しない。

**人間の試遊**：最低5プレイを記録。確認項目は「ルナの嘘を考えたか」「仕事と好意で迷ったか」「結果の信用変化が理解できたか」「夜4の第三択に気づいたか」「夜7の名前ボタンが報酬と感じられたか」「再プレイしたいか」。実際に未試遊なら `未検証` と書く。
